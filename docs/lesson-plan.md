# 教學使用說明

## 建議流程（40 分鐘）

1. 出發任務（5 分）：看主視覺，說出三個觀察到的種子特徵。
2. 世界圖鑑（10 分）：兩人一組，各選一顆種子並猜傳播方式。
3. 種子祕密（13 分）：閱讀風力、水力、動物與自力傳播圖，依序找出「搬運力量—種子構造—移動結果」三個證據，再比較四種方式。
4. 手作或發芽任務（延伸 20–35 分）：依材料與年齡選一項。
5. 闖關挑戰（12 分）：獨立作答後討論誘答選項代表的常見迷思。

## 教師提醒

- AI 圖片用於引起觀察與比較，不作為精確比例或物種鑑定標本。
- 不明、發霉、有毒或受保護的種子不得用於手作。
- 尖銳工具、熱熔膠與鑽孔工作由成人處理。
- 課綱代碼待教師依正式最新版手冊確認。
