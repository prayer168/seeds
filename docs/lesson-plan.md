# 教學使用說明

## 建議流程（40 分鐘）

1. 出發任務（5 分）：看主視覺，說出三個觀察到的種子特徵。
2. 世界圖鑑（10 分）：兩人一組，各選一顆種子並猜傳播方式。
3. 種子祕密（8 分）：整理種皮、胚、養分與傳播構造。
4. 互動觀察（5 分）：播放三種傳播動畫，完成「形狀—方式—位置」口頭推論。
5. 手作或發芽任務（延伸 20–35 分）：依材料與年齡選一項。
6. 闖關挑戰（12 分）：獨立作答後討論誘答選項代表的常見迷思。

## 教師提醒

- AI 圖片用於引起觀察與比較，不作為精確比例或物種鑑定標本。
- 不明、發霉、有毒或受保護的種子不得用於手作。
- 尖銳工具、熱熔膠與鑽孔工作由成人處理。
- 課綱代碼待教師依正式最新版手冊確認。
